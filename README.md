📱 QrCode App
An Android application to scan & generate QR codes, built with Kotlin.
This project is a personal learning app to practice the latest Android technologies.

## ✨ Features

- Scan Qr Code
- Create QrCode
- History Scan and Create
- Settings

---

## 🛠 Tech Stack

- **Language:** Kotlin
- **Architecture:** MVVM
- **UI:** XML
- **Async:** Kotlin Coroutines & Flow
- **Dependency Injection:** Hilt
- **Database:** Room
- **Library : **Barcode scanning ML Kit 
- **Ads:** AdMob
- **Firebase:** Remote Config, Crashlytics, Analytics
