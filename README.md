📱 QrCode App
An Android application to scan & generate QR codes, built with Kotlin.
This project is a personal learning app to practice the latest Android technologies.

✨ Features
📷 Scan QR codes using the camera
🖼️ Detect QR codes from gallery images
➕ Generate QR codes from text, URLs, phone numbers, etc.
🌍 Multi-language support using strings.xml
📡 Google AdMob ads integration (Banner, Native, Interstitial, App Open)
☁️ Remote ads control via Firebase Remote Config


🛠️ Tech Stack

Android Jetpack
ViewBinding
Lifecycle

LiveData
